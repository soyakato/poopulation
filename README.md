# POOPULATION

依存パッケージなしで動く、Canvas製のプロトタイプです。

- `index.html` / `realtime.html` — リアルタイム版
- `tactics.html` — 試験中のタクティクス版（画面はClaude Designのキャンバスから取りこみ）
- `tactics-engine.js` — タクティクス版のゲームロジック。`tactics.html` が読みこむ
- `studio.html` — 排便アニメーションとTACTICSマスタの実動調整画面
- `stages.html` — ステージ・難易度のフォーム編集、検証、JSON書き出し
- `stages.json` — 全24ステージ・4難易度のキャンペーン正本
- `characters.html` / `characters.json` — キャラクターの追加・検証・JSON書き出しと正本
- `sprites.html` / `sprites.json` — キャラクタースプライトのピクセル編集・複製・上書きデータ
- `stage-loader.js` — ステージJSONの検証と難易度反映
- `poop-config.js` — 排便演出と既存キャラクター能力の調整値（JSONが読めない場合の予備設定も保持）

## 開発

ローカルHTTPサーバーでフォルダーを公開し、`index.html`を開いてください。ファイルを直接開くより、モード間リンクとスタジオのプレビューが安定します。

担当者は`studio.html`で演出を、`stages.html`でステージ・難易度を、`characters.html`でキャラクターを、`sprites.html`で見た目を調整します。書き出したJSONをリポジトリの同名ファイルと差し替えると、チーム共通の既定値になります。詳細は`STAGES.md`を参照してください。

## 操作

- リアルタイム：ゴリラをドラッグして、食べさせたい森へ置く
- タクティクス：移動先をクリック、またはゴリラをドラッグ。矢印キーでマスを選び、スペースキー（Enterも可）でそのマスへ移動。行動は`1`〜`5`キーでも選択可能

タクティクスの戦闘値、排便結果、出生、火の延焼、初期マップ、ステージ報酬は決定論的です。同じ操作なら同じ結果になります。`Math.random`は粒子や画面揺れなど、結果に影響しない演出だけに使用しています。ステージ移行時はマップ、森、味方、HP、MP、食べた実、解放・強化を引き継ぎます。

## ステージと戦果

- 既定キャンペーンは全6章・24ステージ、想定30時間です。序盤は4ラウンドから始まり、段階的に長くなります。
- 難易度は「やさしい」「ふつう」「むずかしい」「きわみ」。敵HP・攻撃・数、ラウンド倍率、火、出生条件、味方上限をまとめて切り替えます。
- 各ステージを達成すると森のキャンプへ移り、戦果を1つ選んで次へ進みます。`camp:false`のステージだけは直接次へ進みます。
- 戦果はランダムではなく、常に「新しいゴリラの解放＋即加入」「群れ能力の解放」「恒久ステータス強化」の3系統から選択します。
- 群れ能力は、実の回復量増加、地形MP回復+1、とくぎ消費MP-1の順に解放されます。恒久強化は現在の全員と、今後生まれる仲間に反映されます。
- 後半ステージの敵倍率、地形、ラウンド、襲撃、クリア条件は `stages.html` で編集できます。
- `studio.html` の「キャンプ画面を確認」で、戦果画面をすぐ実動プレビューできます。

## 実とうんち

- タクティクス版では、赤い実で攻撃+2、青い実で最大MP+2、黄色い実で素早さ+2。食べる回数に制限はなく、各ステータスが99になるまで強化できます。
- 黄・赤・青の実は、食べた順に腹へ入り、うんちと同色の森も作ります。青だけが別種のうんちになる例外や、個体ごとの好きな実はありません。
- 黄・赤・青の3色が腹にそろうと、強力なきんのうんちになります。
- 排便時は左端の実から使います。頭上の3枠が現在の順番です。
- 通常の「うんち」は、どの種類・特性のゴリラでも実1個で使用でき、足元1マスへ肥料3を残します。3色がそろった時だけ、きんのうんちになります。
- でかうんちは中心と前後左右の5マスすべてへ肥料6を残します。
- 普通のゴリラの「ロケットうんち」は、実1個とMP5を使い、射程3の指定地点へでかうんちを飛ばします。通常の排便と違い、移動せず離れた土地を育てられます。
- ウィザードゴリラの「めぐみの雨」は指定3×3の全植生へ適用されます。草・若木は1段成長、成木は実+1、火は植生を後退させず消火します。

## 出生と攻撃範囲

- 初期配置か排便由来かを問わず、すべての草木を同じものとして扱います。
- 成木が伐採・着火・焼失を免れて既定で5ターン残ると、その木の色に対応するゴリラがそばに生まれます。出生後、その親木の生存ターンは0から再開します。
- 着火した時点で生存ターンは0へ戻ります。出生可能でも周囲に空きマスがない場合は、空くまで待機します。味方は既定で10匹までです。
- 出生する種類と場所は固定順です。黄は普通／モンキー、赤はガーディアン／シルバー、青はウィザード／チンパンジーで、キャンプで解放済みの種類だけが生まれます。未解放の場合と次の種類は、ゲーム画面下の出生予報に表示されます。
- 普通のゴリラを含む射程1の通常攻撃は、前・後ろ・左・右の4マスです。攻撃を選ぶと全射程が赤、攻撃可能な敵が金で表示されます。
- 出生に必要な成木の生存ターン、味方上限、各キャラの射程は `studio.html` の TACTICS マスタで調整できます。
