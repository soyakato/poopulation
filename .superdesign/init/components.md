# Components

The project has no component framework or shared component directory. It is a dependency-free set of monolithic HTML files. `tactics.html` defines its primitives inline.

## Inline primitives in `tactics.html`

- `.btn`: compact utility/navigation button.
- `.act`: battle action button with disabled and selected states.
- `.screen`: full-canvas overlay used by title, ending, and camp screens.
- `.rule`: compact rules card containing a generated sprite canvas and copy.
- `.start`: primary call-to-action button.
- `.reward` and `.inv-chip`: camp reward and run-inventory controls.

There are no standalone source components to copy in full.
